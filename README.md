# TFWiki-Unusuals
A repository of necessary files for creating Team Fortress Wiki Unusual particle effect renders.

# Contents
This repo contains the following files:
* Raw map file (.vmf) used to set Unusual taunt particle effects.
* BIMP files (.bimp) used to batch-crop the images.
  * Use unusual_hat.bimp for hat effects.
  * Use unusual_taunt.bimp for taunt effects.
* Itemtest file (.itf) to set up the bot with an Unusual hat particle effect.
* VScript file (.nut) to reference in the map and attach the taunt particle effect.
